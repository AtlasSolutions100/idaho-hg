### Real invoice pattern to match (from her PDFs)

**Columns (in this order):**
Date | Product or service | Description | Qty | Rate | Amount

**Product or service format:**
- Use the employee’s name + discipline
- Follow her real style as closely as possible  
  Examples from her invoices:
  - “Contract PT Hodge, Molly”
  - “Eddins, Adrian BSN”
  - “RN contract Edwards, Amber”
  - “Clayton, Sandy RN”

**Description format:**
- Visit type + useful date range (and location code when relevant)
- Examples from her invoices:
  - “TV SOC 7/12-7/25/26”
  - “MC SNV 7/12-7/25/26”
  - “MC mileage 7/12-7/25/26”
  - “MC Per diem 7/12-7/25/26”
  - “RN hours 7/12/26 (8am-8pm)” (for simpler hourly clients)

**Line rules:**
- One line per employee + visit type (aggregated across the period when appropriate)
- Mileage gets its own line
- Per diem gets its own line
- Special items (MI&E, etc.) get their own lines when present
- Hourly work gets clean hourly lines
- If a rate changed mid-period, split the line so amounts stay correct

**Output requirements:**
- On-screen table must use the exact column order above
- CSV download must use the exact same columns and order so she can open it and use it
- Clear grand total
- Missing-rate lines must still be visibly flagged (never silently $0)
